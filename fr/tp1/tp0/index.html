Nombres complexes¶

Un nombre complexe zzz s’écrit z=x+j∗yz = x + j* yz=x+j∗y, où xxx et yyy sont des nombres réels.

c1 = complex(0, 0)

print(c1)
x = 2
y = 3
c2 = complex(x, y)

print(c2)

Module¶

Le module d’un nombre complexe z=x+j∗yz = x + j* yz=x+j∗y est donné par la formule (x2+y2)\sqrt {(x^2 + y^2)}(x2+y2)​

from math import sqrt

absc2 = sqrt(x**2 + y**2)
print(absc2)

On peut aussi utiliser la fonction abs()abs()abs().

absc2 = abs(c2)
print(absc2)
absc1 = abs(c1)
print(absc1)

Moyennes¶

Moyenne arithmétique¶

Si a1,a2,…,ana_1, a_2, \ldots, a_na1​,a2​,…,an​ sont des nombres, la moyenne arithmétique est :

A=1n∑i=1nai=a1+a2+⋯+annA=\frac{1}{n}\sum_{i=1}^n a_i=\frac{a_1+a_2+\cdots+a_n}{n}A=n1​i=1∑n​ai​=na1​+a2​+⋯+an​​
(1)
num = np.linspace(1.0, 100.0, num=100)

a = np.mean(num)
print(a)

Moyenne géométrique¶

from scipy.stats import gmean

g = gmean(num)
print(g)

Si a1,a2,…,ana_1, a_2, \ldots, a_na1​,a2​,…,an​ sont des nombres, la moyenne géométrique est :

(∏i=1nai)1n=a1a2⋯ann\left(\prod_{i=1}^n a_i\right)^\frac{1}{n} = \sqrt[n]{a_1 a_2 \cdots a_n}(i=1∏n​ai​)n1​=na1​a2​⋯an​​
(2)

Si a1,a2,…,ana_1, a_2, \ldots, a_na1​,a2​,…,an​ sont des nombres, la moyenne harmonique est :

H=n1a1+1a2+⋯+1an=n∑i=1n1ai=(∑i=1nai−1n)−1.H = \frac{n}{\frac1{a_1} + \frac1{a_2} + \cdots + \frac1{a_n}} = \frac{n}{\sum\limits_{i=1}^n \frac1{a_i}} = \left(\frac{\sum\limits_{i=1}^n a_i^{-1}}{n}\right)^{-1}.H=a1​1​+a2​1​+⋯+an​1​n​=i=1∑n​ai​1​n​=⎝⎛​ni=1∑n​ai−1​​⎠⎞​−1.
(3)

Classification¶

Comprendre le jeu de données IRIS¶

from sklearn.datasets import load_iris

data = load_iris()

# Target Classes and Names
for target, name in enumerate(data.target_names):
    print(target, name)
# Features
for feature in data.feature_names:
    print(feature)
X = data.data
Y = data.target

print(f"Data size: {len(X)}")
# Printing the data

for x, y in zip(X, Y):
    print(f" {x}: {y} ({data.target_names[y]})")
from sklearn.model_selection import train_test_split

# Random state ensures reproducibility
X_train, X_test, Y_train, Y_test = train_test_split(
    X, Y, test_size=0.33, random_state=42
)

print(f"Training data size: {len(X_train)}")
print(f"Test data size: {len(X_test)}")
from sklearn.metrics import ConfusionMatrixDisplay
import matplotlib.pyplot as plot


def display_confusion_matrix(classifier, title):
    disp = ConfusionMatrixDisplay.from_estimator(
        classifier,
        X_test,
        Y_test,
        display_labels=data.target_names,
        cmap=plot.cm.Blues,
        normalize="true",
    )
    disp.ax_.set_title(title)
    plot.show()
## Classifier
from sklearn import svm, metrics

for kernel in ["linear", "rbf", "poly"]:
    print("")
    classifier = svm.SVC(kernel=kernel, gamma=10)
    classifier.fit(X_train, Y_train)

    predicted_values = classifier.predict(X_test.reshape((X_test.shape[0], -1)))

    # classification report
    title = "SVM classifier with" + kernel + " kernel"
    print(metrics.classification_report(Y_test, predicted_values))
    display_confusion_matrix(classifier, title)
